= Back up Oracle Database workloads using NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Back up Oracle Database protection groups or individual databases from on-premises ONTAP systems using NetApp Backup and Recovery. Send backups to cloud storage including Amazon S3, NetApp StorageGRID, Microsoft Azure Blob Storage, or ONTAP S3.

NOTE: To back up protection groups or single databases on a schedule, create policies that manage backup and restore operations. See link:br-use-policies-create.html[Create policies] for instructions.

* Create protection groups to manage backup and restore operations for a set of resources. See link:br-use-kvm-protection-groups.html[Create and manage protection groups for Oracle Database workloads with NetApp Backup and Recovery] for more information.
* Create an on-demand backup of a protection group.
* Create an on-demand backup of a database.

== Create an on-demand backup of a protection group

Create an on-demand backup before making system changes to protect your data.

*Required Console role*
Backup and Recovery super admin or Backup and Recovery backup admin role. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html[Learn about NetApp Console access roles for all services^].

.Steps 

. From the NetApp Console menu, select *Protection > Backup and Recovery*.
. Under *Workloads*, select the *Oracle* tile.
. Select *Inventory*. 
. Select a workload to view the protection details. 
. Select the Actions icon image:../media/icon-action.png[Actions option] > *View details*.   
. Select the *Protection Groups* tab. 
. Select the protection group that you want to back up.
. Select the Actions icon image:../media/icon-action.png[Actions option] > *Back up now*.
+
NOTE: NetApp Backup and Recovery uses the same policy for both the backup and the protection group.

. Select the schedule tier.
. Select *Back up*. 

== Create an on-demand backup of a database

Create an on-demand backup before making system changes to protect your data. 

*Required Console role*
Backup and Recovery super admin or Backup and Recovery backup admin role. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html[Learn about NetApp Console access roles for all services^].

.Steps 

. From the NetApp Console menu, select *Protection > Backup and Recovery*.
. Under *Workloads*, select the *Oracle* tile.
. Select *Inventory*. 
. Select a workload to view the protection details. 
. Select the Actions icon image:../media/icon-action.png[Actions option] > *View details*.   
. Select the *Databases* tab. 
. Select the database that you want to back up.
. Select the Actions icon image:../media/icon-action.png[Actions option] > *Back up now*.
. Select the schedule tier.
. Select *Back up*.
