= NetApp Backup and Recovery IAM roles
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use Identity and Access Management (IAM) to control which NetApp Backup and Recovery features and actions each user can access.

To learn about IAM roles that are specific to NetApp Backup and Recovery, see https://docs.netapp.com/us-en/console-setup-admin/reference-iam-backup-rec-roles.html[NetApp Backup and Recovery roles in NetApp Console^].
