= Known limitations with NetApp Backup and Recovery for Kubernetes workloads

:nofooter:

[.lead]
Review the current limitations and workarounds for Kubernetes workloads in NetApp Backup and Recovery.

== Limitation in the Backup and Recovery preview for NetApp Console local deployment
 
In the Backup and Recovery preview release for NetApp Console local deployment, backups to object storage are supported only for ONTAP S3 and StorageGRID destinations. Backup archiving is not supported in this preview release.

== Changing the protection policy for an application

If you change an application's protection policy to use a different bucket or secondary replication target, protection can fail.

*Workaround*: Remove the application and add it again.

== 3-2-1 protection policy configuration limitation

If you create a 3-2-1 protection policy that schedules object storage backups separately from replication to secondary storage, protection can hang.

*Workaround*: Remove the application and add it again, and then protect it with a different protection policy.
