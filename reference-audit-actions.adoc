= Audited NetApp Backup and Recovery actions
:table-caption!:
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use this reference to see which NetApp Backup and Recovery actions NetApp Console records on the Audit page. For details about viewing and filtering audit events, see https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#audit-user-activity-from-the-audit-page[Audit user activity from the Audit page^] in the NetApp Console documentation.

For each audited action, NetApp Console records the service name, agent, resource, user, and action status.

.Audited Backup and Recovery actions
[cols="1,3",options="header"]
|===
| Category | Actions

| Restore and recovery
a|
* Restore files from snapshot
* Restore volume or files from backup
* Revert volume to snapshot
* Start file explore

| Backup and snapshot operations
a|
* Create ad hoc cloud backup
* Create ad hoc snapshot
* Delete Azure NetApp Files snapshot policy
* Enable backup in a volume
* Refresh volume backup metadata (scheduled)

| Protection and replication
a|
* Initialize protection for system
* Initialize source protection
* Initialize target protection
* Peer clusters for protection
* Start volume replication

| Panoramic protection
a|
* Activate panoramic protection in a system
* Enable panoramic protection for volumes
* Modify panoramic protection for volumes
* Modify panoramic protection in a system

| Backup migration
a|
* Migrate backups between ONTAP systems
* Validate backup migration

| Cyber Vault management
a|
* Create Cyber Vault system
* Delete Cyber Vault system
* Disable Cyber Vault access
* Enable Cyber Vault access

| Object storage management
a|
* Create object storage bucket
* Modify object storage bucket
* Modify object storage for system

| Cloud credential management
a|
* Delete cloud credentials
* Register cloud credentials
* Update cloud credentials

| Discovery and configuration
a|
* Discover volumes and relationships
* Update application configuration
|===
