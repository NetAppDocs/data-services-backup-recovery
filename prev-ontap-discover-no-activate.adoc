= Discover ONTAP systems and volumes without activating NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Discover ONTAP systems and volumes before you activate NetApp Backup and Recovery. After discovery, you can review the volumes, but you can't protect them until you activate Backup and Recovery.

.Steps

. Go to *Protection > Backup and Recovery*.
. Select the *Volumes* tile.
+
The Volumes dashboard appears.
. Select *Discover systems*.
. In the list, select all systems whose volumes you want to discover.
. Select *Discover*.
. In NetApp Backup and Recovery, select *Inventory*.
+
The discovery process begins. You can see the status and result of discovery in the Job Monitor.
