= Known limitations for VMware workloads in NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Review these limitations before using NetApp Backup and Recovery for VMware workloads.

NetApp Backup and Recovery does not support the following actions for VMware workloads:

* In the Backup and Recovery preview release for NetApp Console local deployment, backups to object storage are supported only for ONTAP S3 and StorageGRID destinations. Backup archiving is not supported in this preview release.
* vVol support
* Email integration
* Role-based access control (RBAC) support
