= Create and manage reports in NetApp Backup and Recovery
:hardbreaks:
:icons: font
:imagesdir: ./media/

[.lead]
Create reports in NetApp Backup and Recovery to review protection status and details for any workload, including counts of successful and failed backups, backup types, storage systems, cluster health, and timestamps. Run a report once or on a schedule, and then view, download, or delete the generated reports.

*Required NetApp Console role*
Backup and Recovery super admin, Backup and Recovery backup admin, Backup and Recovery restore admin, or Backup and Recovery clone admin. If you are protecting data stored on a Cloud Volumes ONTAP cluster, the Cloud Volumes ONTAP Admin role is also required. Learn about link:reference-roles.html[Backup and recovery roles and privileges]. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html[Learn about NetApp Console access roles for all services^].

== Report types

When you create a report, you choose one of the following report types.

[cols="1,3",options="header"]
|===
| Report type | Description
| Protection overview | A complete overview of your protection status, including inventory and restore summaries.
| Usage and charges | Usage and charge details for each workload or resource.
| Status summary | The status of all scheduled and on-demand jobs, with details for each job.
| Audit report | An audit trail of all actions and events performed in the system.
| Kubernetes overview | Protection and backup status for your Kubernetes clusters, applications, and namespaces.
|===

== Create a report

Create a report to review the protection status of your account, specific agents, specific hosts, or specific workloads. You can run the report once or on a recurring schedule.

.Steps

. From the NetApp Backup and Recovery menu, select *Reports*, and then select *Go to new reports* if the *Protection reports* page appears.
. Select *Add report*.
. In *Select report type*, choose a report type and select *Proceed*.
. In *Report name*, enter a unique name for the report.
+
The name must be between 3 and 100 characters, can include only letters, numbers, spaces, underscores (_), and hyphens (-), and must start with a letter.
. Under *Scope*, select the level at which the report collects data:
+
* *By account*: Include everything in the account. No further input is needed.
* *By agent*: In *Agent*, select one or more Console agents. The report includes only the resources managed by the selected agents.
* *By host*: In *Select host*, choose one or more hosts and select *Accept*. Use this option for workloads that run on hosts, such as Microsoft SQL Server and Oracle Database.
* *By workload*: In *Workloads*, choose one or more workload types.
+
NOTE: The *By workload* list does not include ONTAP Volumes. To create a report for ONTAP Volumes, use the *By account* or *By agent* scope.

. Under *Frequency*, choose how often to run the report:
+
* *One time*: Run the report once. This is the default.
* *On schedule*: Run the report repeatedly. In *Run every*, choose a frequency. Scheduled reports appear on the *Scheduled reports* tab.

. Under *Report delivery options*, optionally enable *Email the report results when the report runs*.
+
This option is disabled by default. By default, reports are sent to all users in the organization. To send reports to specific recipients, configure email notifications on the *Settings* page under *Notifications*. For details about configuring email notifications, see link:br-start-configure.html[Configure settings].

. Under *Retention*, in *Keep for*, choose how long to keep the report before it is deleted. 30 days is the default.
. Select *Add*.
+
The report appears at the top of the *Generated reports* list. When the report is ready, a success message appears and you can download or delete the report.

The *Generated reports* list shows the name, type, range, generation time, and user for each report. The *Scope* column summarizes what the report covers, for example "1 Account" or "1 Agent". Select *View* in the *Scope* column to open the report. The range shows N/A for one-time reports.

== Download a report

Download a generated report so that you can review and share it.

.Steps

. From the NetApp Backup and Recovery menu, select *Reports*.
. On the *Generated reports* tab, find the report that you want to download.
. In the report's row, select *Download*, and then choose a format:
+
* *Download JSON*
* *Download PDF*
* *Download Excel*
* *Download CSV*
+
You can also use the *Download* menu on the report page.
+
Large reports can take longer to prepare.

== View a report

View the details of a generated report within NetApp Backup and Recovery, including a summary, inventory counts, and detail tables.

.Steps

. From the NetApp Backup and Recovery menu, select *Reports*.
. On the *Generated reports* tab, select the name of the report that you want to view.
. Expand *Inventory* to see counts for systems, SVMs, volumes, hosts, instances, and buckets.
. Scroll down to review the report tables. The tables that appear depend on the report type.
. (Optional) To choose which columns a table shows, select the column icon at the right end of the table header row, select or clear columns, and then select *Apply*.
+
The *Resource Name* column always stays on. Select *Restore default* to return to the default columns.

. To return to the list of reports, select *Reports* at the top of the page.

== Delete a report

Delete a generated report when you no longer need it. Reports are also deleted automatically when their retention period ends.

.Steps

. From the NetApp Backup and Recovery menu, select *Reports*.
. On the *Generated reports* tab, find the report that you want to delete.
. In the report's row, select the delete icon.
. Confirm the action by selecting *Delete*.
