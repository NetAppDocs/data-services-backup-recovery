=== Oracle Database workloads enhancement
In this release, Oracle Database workloads introduces the following enhancement:

*Oracle Data Guard support*: NetApp Backup and Recovery now supports using protection groups to protect primary and standby databases that use Oracle Data Guard for high availability.

For details about protecting Oracle Database workloads, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html[Learn about protecting Oracle Database workloads with NetApp Backup and Recovery].
