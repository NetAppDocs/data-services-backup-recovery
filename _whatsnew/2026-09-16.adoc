=== General NetApp Backup and Recovery enhancements
In this release, KVM, Hyper-V, and VMware workloads introduce the following enhancement:

*Credential selection during VM host discovery*: When you register a KVM, Hyper-V, or VMware host, you can now use credentials that you have already added to Backup and Recovery.

=== Hyper-V workloads enhancements
In this release, Hyper-V workloads introduces the following enhancement:

*Spanning disk protection for VMs*: For CIFS configurations, Backup and Recovery now supports protecting every disk attached to each VM in a protection group. This includes files distributed across multiple ONTAP volumes or ONTAP storage systems (spanning disks) and files limited to a single location.

For details about protecting Hyper-V workloads, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html[Learn about protecting Hyper-V workloads with NetApp Backup and Recovery].

=== ONTAP Volumes workloads enhancement
In this release, ONTAP Volumes workloads introduces the following preview enhancement:

*Daily backup data transfer report*: NetApp Backup and Recovery for Volumes now includes a daily backup data transfer report under the Reports tab, giving you visibility into daily backup and replication data transfer activity across your environment. You can generate the report for the full account or for selected storage systems, filter by date range and protection type, and download the results as a CSV. 

For details about protecting ONTAP Volumes workloads, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html[Learn about ONTAP volume protection with NetApp Backup and Recovery].
