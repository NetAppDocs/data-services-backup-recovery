=== Kubernetes workloads enhancements
In this release, Kubernetes workloads introduces the following enhancements:

* *Trident Protect 26.09*: This release includes Trident Protect 26.09.
* *Improved Role-Based Access Control support*: During resource discovery, you can now better control access to resources by selecting a project or folder to associate with the new cluster. You can also register only the namespaces you want to protect.
* *Restore files and folders*: You can now restore individual files and folders from Kubernetes backups.

For details about protecting Kubernetes workloads, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html[Learn about protecting Kubernetes workloads with NetApp Backup and Recovery].
