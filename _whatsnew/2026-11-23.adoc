=== Kubernetes workloads enhancement
In this release, NetApp Backup and Recovery introduces the following enhancement for Kubernetes workloads:

*Amazon FSx for NetApp ONTAP support with disk-to-disk backup architecture*: You can now create Kubernetes protection policies that use the disk-to-disk backup architecture with Amazon FSx for NetApp ONTAP. Use an FSx for NetApp ONTAP file system as primary storage and another FSx for NetApp ONTAP file system as secondary storage, in the same AWS region or a different AWS region. You can also use Cloud Volumes ONTAP as primary storage and FSx for NetApp ONTAP as secondary storage. Use these policies to protect applications on self-managed Kubernetes clusters on AWS, and set schedules and retention, run backups, and restore the same way you do with on-premises ONTAP systems.

For more information about creating Kubernetes protection policies, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-policies-kubernetes-create.html[Create and manage Kubernetes backup policies in NetApp Backup and Recovery^].

For details about protecting Kubernetes workloads, refer to https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html[Learn about protecting Kubernetes workloads with NetApp Backup and Recovery^].
