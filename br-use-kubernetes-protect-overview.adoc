= Kubernetes protection workflow with NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use NetApp Backup and Recovery to discover, manage, and protect Kubernetes clusters and applications from a single interface.

The following diagram shows the components and basic architecture for Kubernetes backup and recovery and how copies of your data can be stored in different locations:

image:../media/backup-recovery-architecture-diagram.png[Architecture diagram of backup and recovery for Kubernetes workloads]

NetApp Backup and Recovery provides the following benefits for managing Kubernetes workloads:

* A single control plane for protecting applications across multiple Kubernetes clusters, including containers and virtual machines.
* Native integration with NetApp SnapMirror enables storage offload for backup and recovery workflows.
* Incremental forever backups for Kubernetes applications, translating to lower Recovery Point Objectives (RPOs) and Recovery Time Objectives (RTOs).
