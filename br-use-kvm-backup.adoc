= Back up KVM workloads with NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Back up KVM protection groups from on-premises ONTAP systems to Amazon Web Services, Azure NetApp Files, or StorageGRID. When you back up a protection group, NetApp Backup and Recovery backs up the VMs and storage pools in that group and stores the backup in an object store in your public or private cloud account.

NOTE: To run scheduled backups, create policies that govern backup and restore operations. See link:br-use-policies-kvm-create.html[Create KVM protection policies] for instructions.

* Create protection groups to manage backup and restore operations for a set of resources. See link:br-use-kvm-protection-groups.html[Manage KVM protection groups in NetApp Backup and Recovery] for more information.
//* Back up workloads now (create an on-demand backup now).

== Back up protection groups now with an on-demand backup

Run an on-demand backup immediately if you are about to make changes and want a current backup first.

*Required Console role*
Backup and Recovery super admin or Backup and Recovery backup admin role. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html[Learn about NetApp Console access roles for all services^].

.Steps

. From the NetApp Console menu, select *Protection > Backup and Recovery*.
. In the KVM tile, select *Discover and manage*.
. Select *Inventory*.
. Select a workload to view protection details.
. Select the Actions icon image:../media/icon-action.png[Actions option] > *View details*.
. Select the *Protection groups*, *Datastores*, or *Virtual machines* tab.
. Select the protection group that you want to back up.
. Select the Actions icon image:../media/icon-action.png[Actions option] > *Back up now*.
+
NOTE: The policy that is applied to the backup is the same policy that is assigned to the protection group.

. Select the schedule tier.
. Select *Back up*.
