= Protect VMware workloads with NetApp Backup and Recovery
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Use NetApp Backup and Recovery to protect VMware VMs and datastores. You can create fast, space-efficient, crash-consistent, and VM-consistent backups, store them on supported backup targets, and restore VMware workloads to an on-premises VMware host. 

NOTE: This version of NetApp Backup and Recovery supports only VMware vCenter and does not discover vVols or VMs on vVols.  

//You can back up VMware workloads to Amazon Web Services S3 or StorageGRID and restore VMware workloads back to the same or alternate on-premises VMware host. 

//NetApp Backup and Recovery provides fast, space-efficient, crash-consistent, and VM-consistent backup and restore operations for VMs, datastores, and VMDKs. 


Use NetApp Backup and Recovery to implement a 3-2-1 strategy with 3 copies of your source data on 2 different storage systems and 1 copy in the cloud. The benefits of the 3-2-1 approach include:

* Multiple data copies protect against internal and external cybersecurity threats.
* Different types of media help you recover if one type fails.
* You can quickly restore from the on-site copy and use the off-site copies if the on-site copy is compromised.
